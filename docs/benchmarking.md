# 성능 검증

성능 비교는 동일한 입력, 구성, GPU 장치, 드라이버 및 실행 환경에서 수행한다. 준비 구간을
제외한 원시 측정값과 환경 지문을 JSON으로 보존하고 동일 조건을 5회 실행한다.

무복사 판정에는 공통 계측의 전체 프레임 HtoD/DtoH 카운터 0회와 백엔드 프로파일러 추적이
모두 필요하다. NVIDIA 참조 환경에서는 Nsight Systems 추적에 실행 식별자를 연결한다.

30분 부하 검증은 처리율 99% 이상, 프레임 누락·중복 0개, 큐 용량 준수, 준비 구간 이후
GPU 메모리의 지속 증가 없음 및 모든 lease 회수를 확인한다.
