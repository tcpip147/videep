# 성능 및 관측 계약

## 필수 메트릭

- 실행·단계별 입력, 출력, 오류 및 삭제 프레임 수
- 현재 큐 깊이, 최대 깊이, high-watermark와 생산자 대기 시간
- pool의 할당·사용·회수 리소스 수와 peak GPU 메모리
- 단계별 및 전체 p50/p95/p99 지연 시간과 처리량
- 방향별 GPU/CPU 전체 프레임 전송 횟수와 바이트
- 동기화 wait/signal 횟수 및 GPU 대기 시간

메트릭에는 실행, 단계, backend와 장치 식별자를 붙일 수 있지만 픽셀 데이터나 네이티브
리소스 핸들은 포함하지 않는다.

## 벤치마크 결과

결과는 입력·구성·환경 지문, 준비 및 측정 구간, 원시 측정값, 집계값과 프로파일러 증거
위치를 포함해야 한다. 기준 비교는 동일한 지문에서만 유효하다. 무복사 판정에는 전체 프레임
GPU → CPU → GPU 왕복 0회와 백엔드 프로파일러 추적이 모두 필요하다.

## 성능 회귀 판정

동일 조건 5회 실행의 중앙값을 기준으로 처리량 또는 p95 지연이 ±5% 범위를 벗어나면
회귀 후보로 보고한다. 30분 부하 실행에서는 큐 용량 초과, 준비 구간 이후 GPU 메모리의
지속 증가, 프레임 누락·중복 또는 전체 프레임 CPU 왕복이 하나라도 발생하면 실패한다.
