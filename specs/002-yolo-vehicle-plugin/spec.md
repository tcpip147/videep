# 기능 명세: 차량 분석 플러그인 예제

**기능 디렉터리**: `002-yolo-vehicle-plugin`

**작성일**: 2026-09-09

**상태**: 초안

**입력 설명**: "사용자가 참고할 수 있도록 YOLO 모델로 자동차를 찾고 사각형 박스를 그린 뒤, 자동차를 소형·중형·대형으로 구분하여 텍스트로 표시하는 플러그인 예제를 제공한다."

## 사용자 시나리오 및 테스트 *(필수)*

### 사용자 스토리 1 - 차량 검출 결과 확인 (우선순위: P1)

플러그인 개발자는 예제 구성을 실행하여 입력 영상의 자동차가 검출되고, 각 자동차 주위에 사각형 경계 상자가 표시되는 모습을 확인한다.

**우선순위 근거**: 차량 위치 검출과 시각화는 예제의 핵심 가치이며 이후 차급 분류의 전제 조건이다.

**독립 테스트**: 자동차가 포함된 시험 영상을 입력하고, 출력 영상에서 기준 정답에 포함된 자동차가 경계 상자로 표시되는지 확인한다.

**인수 시나리오**:

1. **주어진 조건** 자동차 한 대 이상이 선명하게 보이는 영상이 있을 때, **실행하면** 신뢰도 기준을 충족한 각 자동차 주위에 경계 상자가 표시된다.
2. **주어진 조건** 검출 대상 자동차가 없는 영상이 있을 때, **실행하면** 잘못된 경계 상자를 추가하지 않고 원래 영상을 계속 출력한다.
3. **주어진 조건** 자동차가 일부 가려진 영상이 있을 때, **실행하면** 신뢰도 기준을 충족하는 자동차만 표시한다.

---

### 사용자 스토리 2 - 자동차 크기 등급 표시 (우선순위: P2)

플러그인 개발자는 검출된 자동차마다 별도의 분류 결과인 소형, 중형 또는 대형 등급과 분류 신뢰도를 영상에서 확인한다.

**우선순위 근거**: 차량 검출 예제를 다단계 분석 플러그인으로 확장하여 사용자가 후속 모델 연결 방법을 이해하게 한다.

**독립 테스트**: 차급 정답이 부여된 자동차 영상을 입력하고, 각 경계 상자에 표시된 등급과 정답을 비교한다.

**인수 시나리오**:

1. **주어진 조건** 검출된 자동차의 분류 신뢰도가 기준 이상일 때, **실행하면** 경계 상자에 소형, 중형 또는 대형 중 하나와 신뢰도가 표시된다.
2. **주어진 조건** 분류 신뢰도가 기준 미만일 때, **실행하면** 임의의 등급 대신 `미분류`로 표시한다.
3. **주어진 조건** 한 프레임에 여러 자동차가 있을 때, **실행하면** 각 자동차 영역을 독립적으로 분류하고 해당 상자에 결과를 연결한다.

---

### 사용자 스토리 3 - 예제를 복사하여 사용자 모델로 교체 (우선순위: P3)

플러그인 개발자는 예제와 설명을 참고하여 차량 검출 모델, 차급 분류 모델, 신뢰도 기준과 표시 방식을 자신의 용도에 맞게 교체한다.

**우선순위 근거**: 예제의 목적은 특정 모델을 고정 제공하는 것이 아니라 안전한 플러그인 확장 방법을 보여주는 것이다.

**독립 테스트**: 예제 설정의 모델 위치와 기준값을 다른 유효한 값으로 변경한 뒤 핵심 파이프라인을 수정하지 않고 실행되는지 확인한다.

**인수 시나리오**:

1. **주어진 조건** 호환되는 사용자 모델과 올바른 설정이 있을 때, **교체하면** 핵심 런타임 변경 없이 새 모델로 차량 분석이 수행된다.
2. **주어진 조건** 모델 파일이 없거나 호환되지 않을 때, **초기화하면** 문제의 대상과 원인을 식별할 수 있는 오류가 출력되고 파이프라인이 안전하게 종료된다.
3. **주어진 조건** 사용자가 신뢰도 또는 표시 설정을 변경했을 때, **다시 실행하면** 변경된 설정이 결과에 반영된다.

### 경계 사례

- 경계 상자가 프레임 바깥으로 나가면 표시 및 분류 영역을 유효한 영상 범위로 제한한다.
- 자동차가 너무 작아 분류에 필요한 정보가 부족하면 `미분류`로 처리한다.
- 경계 상자와 텍스트가 겹치거나 프레임 가장자리에 가까우면 읽을 수 있는 위치로 조정한다.
- 동일한 자동차에 중복 검출 결과가 생기면 가장 신뢰도 높은 대표 결과만 표시한다.
- 검출 결과가 매우 많으면 설정된 최대 차량 수까지만 분류하고 나머지는 안전하게 생략한다.
- 모델 초기화 또는 프레임 처리 중 오류가 발생하면 GPU 리소스를 반환하고 오류 단계와 원인을 보고한다.
- 지원되지 않는 프레임 형식이나 크기가 입력되면 묵시적으로 CPU 변환하지 않고 명확한 호환성 오류를 보고한다.

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 예제는 전처리, 추론 및 후처리 구성요소의 역할과 사용자 수정 지점을 설명해야 한다.
- **FR-002**: 예제는 입력 프레임에서 자동차를 검출하고 각 결과에 경계 상자, 객체 신뢰도 및 객체 종류를 생성해야 한다.
- **FR-003**: 예제의 기본 검출 대상은 승용차, 버스 및 트럭을 포함해야 하며 사용자가 대상 종류를 설정할 수 있어야 한다.
- **FR-004**: 예제는 검출된 각 자동차 영역을 별도의 차급 분류 대상으로 처리해야 한다.
- **FR-005**: 차급 분류 결과는 `소형`, `중형`, `대형`, `미분류` 중 하나여야 한다.
- **FR-006**: 차급은 경계 상자의 화면상 크기만으로 추정하지 않고 사용자 제공 분류 모델의 결과로 결정해야 한다.
- **FR-007**: 후처리 결과는 각 자동차의 경계 상자와 차급 및 신뢰도 텍스트를 해당 영상 프레임에 표시해야 한다.
- **FR-008**: 경계 상자 좌표는 항상 실제 프레임 범위 안으로 제한되어야 한다.
- **FR-009**: 사용자는 검출 모델 위치, 차급 분류 모델 위치, 장치, 검출 신뢰도, 분류 신뢰도, 중복 억제 기준, 최대 차량 수 및 표시 색상을 설정할 수 있어야 한다.
- **FR-010**: 모델 파일 또는 설정이 유효하지 않으면 첫 프레임 처리 전에 구체적인 검증 오류를 제공해야 한다.
- **FR-011**: 자동차가 없거나 분류가 불가능한 프레임도 중단 없이 출력되어야 한다.
- **FR-012**: 예제는 한 프레임에 있는 여러 자동차의 검출 결과와 차급 결과를 서로 잘못 연결하지 않아야 한다.
- **FR-013**: 예제는 모델 준비, 설정 변경, 실행, 예상 출력 및 문제 해결 절차를 포함한 한글 사용 설명을 제공해야 한다.
- **FR-014**: 예제의 전처리, 추론 및 후처리 구성요소는 핵심 파이프라인 런타임을 수정하지 않고 각각 교체 가능해야 한다.
- **FR-015**: 정상 영상 처리 경로에서 전체 프레임 픽셀을 GPU에서 CPU로 복사해서는 안 된다.
- **FR-016**: 모델 입력 준비, 차량 영역 추출, 모델 실행 및 시각적 합성은 GPU 상주 프레임 또는 지원되는 무복사 상호운용 표현을 사용해야 한다.
- **FR-017**: CPU로 전달 가능한 데이터는 경계 좌표, 종류, 등급, 신뢰도, 처리 시간과 같은 제한된 추론 메타데이터로 한정해야 한다.
- **FR-018**: 플러그인은 기반 GPU 리소스의 소유권을 획득하거나 수명을 임의로 연장해서는 안 된다.
- **FR-019**: 예제는 프레임별 차량 수, 검출·분류·표시 단계 처리 시간, 미분류 수 및 오류 수를 측정할 수 있어야 한다.
- **FR-020**: 예제는 입력 프레임 순서와 출력 프레임 순서를 보존해야 한다.

### 핵심 엔터티

- **플러그인 예제 구성**: 전처리, 차량 검출, 차급 분류와 결과 표시를 연결하며 모델 및 기준값 설정을 포함하는 참고 자료이다.
- **차량 검출 결과**: 프레임 식별자, 경계 상자, 객체 종류 및 검출 신뢰도로 구성된다.
- **차급 분류 결과**: 차량 검출 결과에 연결된 소형·중형·대형·미분류 등급과 분류 신뢰도이다.
- **표시 결과**: 경계 상자, 텍스트, 색상 및 배치 정보를 포함하며 원본 프레임과 동일한 순서로 출력된다.
- **분석 설정**: 모델 위치, 대상 객체 종류, 신뢰도 기준, 중복 억제 기준, 최대 차량 수 및 표시 규칙이다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: 사용자는 제공된 설명만으로 15분 이내에 예제 설정을 준비하고 기존 파이프라인에서 실행할 수 있다.
- **SC-002**: 정답이 표시된 검증 영상에서 기준 대상 자동차의 90% 이상이 올바른 차량 경계 상자로 표시된다.
- **SC-003**: 분류 가능 기준을 만족하는 검증 자동차 중 85% 이상이 올바른 소형·중형·대형 등급으로 표시된다.
- **SC-004**: 출력 프레임의 100%에서 표시된 경계 상자가 영상 범위를 벗어나지 않는다.
- **SC-005**: 30분 연속 실행 동안 입력 및 출력 프레임 순서가 유지되고 플러그인 오류로 인한 파이프라인 중단이 발생하지 않는다.
- **SC-006**: 정상 처리 경로를 측정했을 때 전체 프레임의 GPU→CPU→GPU 왕복 전송 횟수는 0회이다.
- **SC-007**: 예제 설정에서 모델 및 기준값을 교체하는 작업은 핵심 런타임 파일 변경 없이 완료된다.
- **SC-008**: 모델 누락, 호환되지 않는 입력 및 처리 오류 시험의 100%에서 원인과 발생 단계가 식별 가능한 메시지로 보고된다.

## 가정

- 사용자는 차량 검출용 YOLO 계열 모델과 소형·중형·대형 레이블을 출력하는 별도의 차급 분류 모델을 합법적으로 준비한다.
- 기본 예제는 단일 영상 스트림과 단일 GPU 장치에서 실행한다.
- 차급의 의미와 학습 기준은 사용자가 제공하는 분류 모델의 데이터셋 정의를 따른다.
- 검출 대상의 기본 종류는 승용차, 버스 및 트럭이며 오토바이와 자전거는 기본 범위에서 제외한다.
- 출력 영상의 해상도와 프레임 속도는 기존 파이프라인의 협상 결과를 유지한다.
- 예제는 학습, 데이터셋 제작, 모델 변환 또는 모델 파일 배포 기능을 포함하지 않는다.
- 예제에 필요한 선택적 모델 실행 의존성은 핵심 런타임 의존성과 분리된다.

## 범위 제외

- 차량 추적 및 영구 식별자 부여
- 번호판 검출 또는 문자 인식
- 차량 속도, 실제 물리 크기 또는 이동 방향 추정
- 모델 학습, 재학습 및 데이터 레이블링
- 여러 카메라 간 차량 연계 분석
